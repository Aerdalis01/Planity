# Recodage du site Planity

## 📚 Description

Ce projet consiste à recoder le visuel du site **Planity**, une plateforme de réservation en ligne pour les services de beauté. L'objectif est recoder le visel en utilisant **TypeScript**, **Bootstrap**, **CSS**, et **HTML**.

---

## 🛠️ Technologies Utilisées

- **HTML5** : Structure du site.
- **CSS3** : Personnalisation et design.
- **Bootstrap** : Mise en page et composants responsives.
- **TypeScript** : Gestion de la logique dynamique et typage sécurisé.
